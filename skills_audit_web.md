# Skills Disponibles para Auditoría Web

Este documento detalla las herramientas y habilidades (skills) disponibles para revisar y mejorar la página web de **EFinnovation**.

## 1. Revisión Técnica y de Código
*   **`production-code-audit`**: Escaneo profundo para elevar el código a estándares corporativos, corrigiendo arquitectura y estructura.
*   **`code-review-excellence`**: Evaluación de calidad, mantenibilidad y mejores prácticas de desarrollo.
*   **`senior-architect`**: Análisis de arquitectura escalable (HTML, JS, CSS).

## 2. Rendimiento y SEO
*   **`seo-audit`**: Análisis de indexación, meta-etiquetas y estrategia de contenido para buscadores.

## 3. Diseño y Experiencia de Usuario (UX/UI)
*   **`web-design-guidelines`**: Auditoría de usabilidad y estándares modernos de navegación.
*   **`ui-ux-pro-max`**: Optimización de paletas de colores, tipografía y jerarquía visual.

## 4. Seguridad y Accesibilidad
*   **`vulnerability-scanner`**: Detección de fallos de seguridad comunes (OWASP) y configuraciones de riesgo.
*   **`wcag-audit-patterns`**: Auditoría completa de accesibilidad para asegurar cumplimiento de estándares inclusivos.

## 5. Pruebas Funcionales
*   **`webapp-testing`**: Automatización con Playwright para verificar flujos de usuario, botones y capturas de pantalla reales.
